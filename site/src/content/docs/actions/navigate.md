The `navigate` action declares that activating an element takes the user to a destination — a card whose whole surface opens the product page, a row that drills into detail.

**Status:** specified — this page is the specification. The React and Web Components transforms do not emit it yet; the A2UI target consumes its payload declaration.

It is an **action**, not a role. The [`link` role](/roles/link/) answers what the element *is* — it announces as a link and carries `href` in its contract. `navigate` records the consequence on elements that are *not* links: a card is a container, and nothing in its announcement changes because tapping it goes somewhere. Where the element genuinely is a link, annotate the role and let its contract carry the destination; add `navigate` only when a non-link surface navigates.

## Degradation

An `href` the component does not declare contributes nothing — the destination is then the consumer's to resolve from the component id, which is the honest degrade rather than an invented URL.

## Activation context

Navigation requires a user-activation context: a renderer must never follow a destination the user did not press. Runtime targets mark the behavior accordingly (A2UI `requiresUserActivation`).

## Where to annotate it

On the element whose activation navigates, in the component that owns the surface:

```
action:navigate
```
