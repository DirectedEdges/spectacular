# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Reports for any Specs package or surface — the `@directededges/*` npm packages, the Figma plugin, or the documentation site — are welcome here, whichever repository the fix lands in.

You can expect:

- An acknowledgment within 3 business days.
- An assessment, and a fix timeline when the report is confirmed.
- Credit in the security advisory and changelog, under the name you ask for, unless you prefer none.

Please don't open public issues for suspected vulnerabilities, and allow a coordinated disclosure window before publishing details.

## Supported versions

Fixes ship in the current release line of each package. Older versions are not patched; the advisory for a fixed vulnerability names the versions affected and the version to upgrade to.
